# Contributing

Read STYLE.md, NOTATION.md and AUTHOR-CHECKLIST.md before editing.

Keep each scientific change scoped to one chapter or scheme. Shared tooling changes belong in a separate change. Coordinate conflicting scientific claims with the report maintainer.

Use a contributor fork branch for review into UCzhangxi/pyharp:tech-report. Only the maintainer decides whether to open and merge an upstream pull request.

Run the tool tests, code citation and anchor checks, render gate and ratchet gate. Regenerate appendix fragments after changing their inputs. Keep generated HTML and PDF as build artifacts.

Contributor assignments are deliberately absent. Preserve scholarly attribution and named scientific methods. No numerical findings are implied by a passing skeleton render.
